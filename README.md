# Spring Security Library

## Description 
Ceci est un petit projet de formation pour la mise en application de Spring Security.
Ce projet démarre de zéro avec la configuration des pages JPA, de l'architecture globale du projet ainsi que de la sécurisation de l'application.

## Stack technique
- Spring Boot
- Spring Security
- Spring JPA

## Collection Bruno
Afin de voir les routes de l'API et comment les utiliser, le plug-in Bruno a été utilisé. Celui-ci a généré
une collection complète de ce qui a été implémenté. Elle est consultable dans le dossier `springSecurity-Library > requests`,
juste au-dessus du fichier `src`.
En cas de doute, faire une recherche pour les fichiers avec une extension `.bru`.
